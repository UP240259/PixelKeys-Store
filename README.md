# 🎮 PixelKeys Store

PixelKeys Store es una aplicación web full-stack para la gestión y visualización de un catálogo de videojuegos digitales. El proyecto implementa una arquitectura desacoplada utilizando un backend construido en NestJS, una interfaz web interactiva en React (con Vite) y almacenamiento persistente en MySQL.

## 🏗️ Arquitectura del Sistema

* **Frontend:** React + Vite + Axios + Lucide React (Icons).
* **Backend:** NestJS + TypeScript + TypeORM / Class-Validator.
* **Base de Datos:** MySQL.
* **Pruebas de API:** Bruno API Client.
